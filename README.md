# Labiomol - Bioinformática

Repositório de recursos em bioinformática. Aqui ficam scripts de análise e matrizes de contagem processadas de projetos com dados públicos do lab.

Os dados são de bases públicas, mas o acesso ao repositório é restrito aos membros do lab.

## Organização

- `data/` — matrizes de contagem processadas
- `scripts/` — scripts de análise em R e Python
